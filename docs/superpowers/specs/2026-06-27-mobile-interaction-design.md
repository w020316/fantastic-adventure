# 移动端交互优化设计

> 日期：2026-06-27
> 目标：消除移动端与桌面端的交互体验差异，为触屏设备提供等价的动态效果

## 问题背景

当前项目有 3 个桌面端交互效果在移动端完全缺失：

1. **姓名揭示**（HeroSection）：鼠标靠近"周末"文字时中文名渐变为英文名"Cris"，移动端直接禁用
2. **3D倾斜卡片**（TiltCard/CapabilitySection）：鼠标移动时卡片产生3D倾斜+光泽，移动端无效果
3. **光斑跟随**（SpotlightCursor）：荧光绿光斑跟随鼠标，移动端直接禁用

## 设计方案

### 1. 姓名揭示 - 自动循环动画

**触发方式**：触屏设备下，姓名进入视口后自动循环
**动画周期**：每 4 秒一个循环（显示中文 2.5s → 渐变到英文 0.5s → 显示英文 1s → 渐变回中文 0.5s → 重复）
**实现**：在 HeroSection 中检测触屏设备，使用 `setInterval` 驱动 `revealProgress` 在 0↔1 之间循环
**桌面端**：保持原有鼠标驱动逻辑不变

### 2. 3D倾斜卡片 - 陀螺仪驱动

**触发方式**：触屏设备下，使用 `DeviceOrientationEvent` 监听设备倾斜
**映射逻辑**：
- `event.beta`（前后倾斜，-180~180）→ `rotateX`（-maxTilt~maxTilt）
- `event.gamma`（左右倾斜，-90~90）→ `rotateY`（-maxTilt~maxTilt）
**iOS 权限处理**：iOS 13+ 需要 `DeviceOrientationEvent.requestPermission()`，在首次触摸时请求
**降级方案**：不支持陀螺仪的设备，卡片进入视口时播放一次 3D 入场旋转动画
**桌面端**：保持原有鼠标驱动逻辑不变

### 3. 光斑跟随 - 触摸跟随

**触发方式**：触屏设备下，手指触摸屏幕时在触摸点产生光斑
**视觉表现**：与桌面端相同的荧光绿径向渐变光斑，跟随手指移动
**实现**：监听 `touchstart` 和 `touchmove` 事件，更新光斑位置；`touchend` 时淡出
**桌面端**：保持原有鼠标驱动逻辑不变

## 涉及文件

| 文件 | 改动内容 |
|------|---------|
| `src/components/landing/HeroSection.tsx` | 添加触屏自动循环动画逻辑 |
| `src/components/ui/TiltCard.tsx` | 添加陀螺仪驱动 + iOS权限处理 + 降级入场动画 |
| `src/components/landing/SpotlightCursor.tsx` | 添加触摸跟随逻辑 |
| `src/hooks/useMobile.ts` | 无需修改（已有触屏检测） |

## 技术约束

- 所有移动端逻辑必须通过 `(hover: none)` 媒体查询或触屏检测激活，不影响桌面端
- 尊重 `prefers-reduced-motion`，减少动画时禁用循环和陀螺仪
- iOS 陀螺仪权限请求需用户手势触发（首次触摸）
- 陀螺仪事件需在组件卸载时正确清理

## 验收标准

1. 手机端访问首页，"周末"文字自动在中英文间渐变循环
2. 手机端倾斜手机，能力卡片产生3D倾斜效果
3. 手机端触摸屏幕，触摸点出现荧光绿光斑
4. 桌面端所有交互效果保持不变
5. 开启"减少动画"系统设置时，循环动画和陀螺仪禁用
